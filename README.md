# ميزان الأسعار ⚖️

**مشروع برمجي لتحليل أسعار المنتجات والطلب واقتراح أسعار ديناميكية.**

يقرأ المشروع مبيعات المنتجات الأسبوعية وتكلفة المنتج ومخزونه وسعره الحالي، ثم يحسب توقعًا مبسطًا للطلب ويقارن أسعارًا بديلة لاختيار السعر الأعلى ربحًا وفق الافتراضات المحددة.

> **تنبيه:** هذا نموذج بحثي قائم على حسابات إحصائية وافتراضات مرونة السعر، وليس نموذج ذكاء اصطناعي مدرّبًا أو نظامًا جاهزًا لتعديل أسعار المتاجر تلقائيًا. الأرباح المتوقعة محاكاة وليست ضمانًا.

## المميزات

- توقع مبسط للطلب اعتمادًا على متوسط مرجّح للمبيعات الأسبوعية، مع إعطاء وزن أكبر للأسابيع الحديثة.
- اقتراح أسعار بديلة باستخدام نموذج مرونة الطلب بالنسبة للسعر.
- احترام الحد الأدنى لهامش الربح ونسبة التغيير القصوى للسعر.
- مراعاة كمية المخزون المتاحة.
- قراءة المنتجات من ملف CSV وإخراج التوصيات في ملف JSON.
- اختبارات آلية وملف GitHub Actions للتحقق من المشروع.
- لا يحتاج مفاتيح API أو حسابًا في سلة للتشغيل محليًا.

## التشغيل

يتطلب Python 3.10 أو أحدث. من داخل مجلد المشروع:

```bash
python -m pip install -e .
python -m nexprice.cli --input examples/products.csv --output recommendations.json
python -m unittest discover -s tests -v
```

## ملف البيانات

يوجد مثال جاهز في `examples/products.csv`. أسماء الأعمدة الداخلية بالإنجليزية لتسهيل التعامل البرمجي:

| العمود | المعنى |
|---|---|
| `sku` | رمز المنتج |
| `price` | السعر الحالي |
| `unit_cost` | تكلفة الوحدة |
| `stock` | المخزون |
| `weekly_units` | عدد الوحدات المباعة أسبوعيًا، مفصولة بفاصلة منقوطة `;` من الأقدم للأحدث |
| `min_margin` | الحد الأدنى لهامش الربح (اختياري) |
| `max_change` | الحد الأقصى لنسبة تغيير السعر (اختياري) |
| `elasticity` | افتراض مرونة الطلب السعرية، ويجب أن يكون سالبًا (اختياري) |

## كيف يعمل؟

1. يتوقع الطلب باستخدام متوسط مرجّح للمبيعات التاريخية.
2. يجرب أسعارًا ضمن نطاق التغيير المسموح.
3. يقدر الطلب لكل سعر وفق المعادلة: `demand = forecast * (candidate_price / current_price) ** elasticity`.
4. يقيد المبيعات المتوقعة بالمخزون، ويحسب الربح الإجمالي التقريبي.
5. يختار السعر الأعلى ربحًا من الأسعار التي تستوفي شروط الهامش والتغيير.

## حدود النموذج

لا يستنتج البرنامج مرونة السعر من البيانات تلقائيًا، ولا يراعي حاليًا ضريبة القيمة المضافة أو الشحن أو المرتجعات أو رسوم المنصة أو أسعار المنافسين أو العروض الموسمية. لا يغيّر أسعار أي متجر فعليًا. ويمكن إضافة ربط مع **سلة** لاحقًا بعد التحقق من واجهات API والصلاحيات المطلوبة.
